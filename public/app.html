Screens

Words have to be drawn to appear in a picture. Each of these is a web page with a transparent background showing the line that is current right now — open one as a vMix Browser input and lay it over the video. One page per destination, because each gets different words at a different moment.

YouTube captions do not use these. They are sent to YouTube as text and the viewer switches them on, so there is no page to point anything at. YouTube hands you that URL when you switch the stream's captions to "POST to URL"; it goes in Settings → Keys and passwords.
